# 视觉方向讨论记录

日期：2026-11-05。状态：方向已确认；配色、字体、具体布局和动效参数尚未通过原型选择，尚无界面实现。

## 已确认的方向

- 默认采用专业、中性、清晰的桌面项目工作台，面向更广泛用户。
- 保留游戏库式项目封面浏览的特点，角色插画与个人封面作为可选个性化。
- 用户希望有动态排版、视差效果和颗粒质感。
- 用户接受浅色与深色主题、自定义封面，以及封面和列表两种展示方式的方向。

## 效果使用建议

动态排版建议用于窗口大小变化、分组筛选及封面与列表切换时的布局过渡。状态更新时保持项目顺序和操作位置稳定，避免用户正在点击时控件移动。具体效果仍需原型确认。

视差建议集中在项目封面和详情插画等展示区域，采用小幅、可关闭的位移。启动按钮、日志、环境报告和容器操作区域保持稳定，滚动和指针交互遵循正常桌面行为。

颗粒质感建议采用低强度静态纹理作为背景或封面叠层；不影响文字、错误信息和状态辨识。首版优先静态纹理，避免持续刷新噪声带来的无意义负载。

主题与个人封面可以改变视觉表达，但操作位置、状态语义、告警优先级与数据关系一致。没有自定义图片时提供正常默认展示，不强迫用户准备封面。

## 可访问性与性能建议

- 识别系统减少动态效果设置，并提供应用内动效开关；减少动态效果时关闭视差和明显布局移动，保留直接、可读的状态。
- 动效用于反馈和空间变化，不能拖延启动、停止或维护操作。
- 大量项目采用合适的图片尺寸、按需加载和列表渲染策略；后台托盘运行时停止不可见的装饰动效。
- 颗粒纹理不拦截输入，不降低正文可读性，主题切换后仍需检查对比度。
