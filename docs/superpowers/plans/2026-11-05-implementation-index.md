建议采用 Native：由当前会话逐项实现，每个任务测试并提交，整体完成后独立审阅。另一选择是 Subagent-driven：各任务交由新代理实现并逐项独立审阅；审阅更频繁，但上下文成本更高。无论选择哪种，都不减少测试或修改原项目的边界。

## 完成交付的限制

管理器模拟测试通过不能代替原项目真实生命周期。typing-tracker和WeChatBot需要各自的安全控制服务端；这些是独立可评审变更，不能自动修改原项目或结束真实微信。Go/Web项目以用户选定的本地源码为准，既有容器归属另外核对。

第一份计划即可交付可测试核心；最终首版完成还需要三个项目真实隔离验收。配置包不包含源码、运行时、镜像、模型、密钥和业务数据，不能宣传为离线全量搬家。
